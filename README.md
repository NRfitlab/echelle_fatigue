# Échelle de fatigue

PWA indépendante pour un questionnaire hebdomadaire sur la fatigue.

## Fichiers
- `index.html` : application principale
- `manifest.json` : configuration PWA
- `service-worker.js` : cache hors ligne
- `icons/` : icônes PWA
- `supabase.sql` : création de la table et politiques RLS

## Installation
1. Exécuter `supabase.sql` dans Supabase SQL Editor.
2. Déposer tous les fichiers à la racine du dépôt GitHub.
3. Activer GitHub Pages sur la branche `main`, dossier `/ (root)`.
